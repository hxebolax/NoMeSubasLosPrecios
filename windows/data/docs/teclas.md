# Teclas de No Me Subas Los Precios

## Ventana principal

- Control+N: añadir un producto (la dirección se rellena sola si la ha copiado).
- Control+I: importar.
- Control+E: exportar.
- F5: comprobar todos los productos ahora.
- Control+F: ir al campo de búsqueda. Intro o flecha abajo en la búsqueda llevan a la lista.
- Control+1 a Control+7: secciones Todos los productos, Categorías, Tiendas, Ofertas, Favoritos, Comparar y Avisos.
- Control+, (coma): preferencias.
- F1: manual.
- Control+F1: esta lista de teclas.
- Control+H: ayuda del control que tiene el foco.
- Alt+F4: cerrar la ventana (la aplicación sigue en la bandeja si así está configurado). Para salir del todo: Archivo, Salir.

## Lista de productos

- Intro: detalles del producto.
- Control+Intro: abrir en el navegador.
- Mayúsculas+F5: comprobar ahora el producto.
- F2: editar el producto.
- Control+M: mover a otra categoría.
- Control+D: marcar o quitar de favoritos.
- Control+P: pausar o reanudar la comprobación.
- Control+Mayúsculas+C: copiar el enlace.
- Suprimir: eliminar el producto (pide confirmación).
- Tecla Aplicaciones o Mayúsculas+F10: menú del producto.
- Flecha izquierda y flecha derecha: leer las columnas una a una.

## Detalles del producto

Botones, con Alt más la letra indicada:

- N: abrir en el navegador. A: comprobar ahora. E: editar.
- P: elegir el precio en la página (lista de importes encontrados).
- V: elegir variante (si el producto tiene un precio «desde»).
- T: abrir la tienda en el navegador integrado; Escape lo cierra.
- L: copiar el enlace. Escape: cerrar los detalles.

## Visor de ayuda

- F3: buscar siguiente.

## Lista de avisos

- Intro: abrir el producto del aviso y marcarlo como leído.
- Suprimir: borrar el aviso.
- Tecla Aplicaciones: marcar como leído o no leído, marcar todos como leídos, borrar todos.

## Diálogos

- Escape: cerrar o cancelar.
- Intro: botón predeterminado (Aceptar, Guardar...).
- Alt más la letra subrayada: ir a ese campo o pulsar ese botón.
- Control+H: ayuda del control que tiene el foco.
